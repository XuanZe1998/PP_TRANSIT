# Linknux UI/UX 设计系统

## 设计目标

Linknux 使用统一的专业浅色科技 SaaS 视觉。官网负责建立可信度和转化，用户工作台强调任务完成，管理后台强调信息密度；三类界面共享同一套色彩、字体、间距、状态和组件规范。

## 基础令牌

- 品牌主色：#2563EB；悬停/聚焦表面：#EAF2FF；辅助青色：#0891B2。
- 页面背景：#F4F7FB；内容表面：#FFFFFF；弱表面：#F7FAFC。
- 主文字：#18314F；正文：#475569；辅助文字：#64748B；边框：#D8E3F0。
- 成功：#08734F / #E8F8F1；警告：#8A5A0A / #FFF6D9；危险：#9F2636 / #FFF0F2。
- 字体：Inter、Noto Sans SC、PingFang SC、Microsoft YaHei、sans-serif。
- 间距以 8px 为基准；常用间距为 8/12/16/24/32/48px。
- 控件圆角 10px，内容卡片圆角 14px；阴影仅用于浮层和关键内容层级。
- 全站固定浅色模式；不使用动画或过渡效果。

## 页面网格

- 官网内容宽度上限 1248px，桌面左右留白至少 32px；内容区使用 12 列网格。
- 用户工作台桌面侧栏 248px，正文区域自适应；页面标题与主操作固定在内容首部。
- 管理后台桌面侧栏 256px，正文使用高密度工具栏、指标区和数据区。
- 1200px 以下压缩卡片列数，900px 以下工作台侧栏改为抽屉，680px 以下所有多列表单改为单列。
- 390px 视口不得出现页面级水平滚动；宽表只能在其明确的滚动容器中横向滚动。

## 组件状态

- 主按钮每个操作组最多一个；次按钮使用白色表面和品牌边框；危险操作始终使用危险色语义。
- 输入控件默认白底，聚焦时使用 1px 品牌边框和外层聚焦环；错误信息紧邻字段。
- 卡片不嵌套卡片；统计卡只展示标签、主要数值和一条必要说明。
- 表格表头使用弱品牌表面，数值右对齐，主要标识与操作列可固定；移动端保持表格滚动，不压缩到不可读。
- 标签同时使用文字和颜色表达状态，不以颜色作为唯一信息载体。
- 弹窗和抽屉必须适配短视口，正文区域独立滚动，主要提交操作始终可达。
- 空状态说明原因并给出唯一下一步；错误状态保留上下文并提供重试。
- 分页默认 10 条，可选 10/20/50/100；总数不超过 200 时才提供“显示全部”。

## 三类样板的设计意图

### 官网

首页首屏采用品牌价值主张、两个明确 CTA 和可解释的统一网关产品预览。移动导航保留 Logo、免费接入和菜单入口，不再横向滚动。

### 用户工作台

总览首先回答余额、用量、Key 和请求状态，然后提供用量趋势、接入信息和常用任务。桌面使用任务侧栏，移动端改为顶部栏和菜单抽屉。

### 管理后台

总览首先呈现请求量、收入、毛利和告警，再展示趋势与近期异常。筛选、主要操作和刷新时间处于同一工具栏；复杂数据表保留高密度但提高扫描性。

## 可访问性与验收

- 正文与背景对比度达到 WCAG 2.1 AA；交互控件必须有可见键盘焦点。
- 触摸目标至少 44×44px；关键操作不依赖悬停。
- 支持 1440×900、1366×768、768×1024 和 390×844。
- 加载、空数据、失败、禁用和成功状态均需有可辨识的文字反馈。
