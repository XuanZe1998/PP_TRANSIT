# 模型网关操作

进入“模型网关”，使用“上游与分组”“模型与定价”“运行记录”三个页面。

一级筛选对应独立站点，二级对应上游分组。站点使用稳定 ID，改名不会改变路由。AiAPIBank、好易智算保留各自报价适配器，New API 兼容站点独立接入。

接入时填写地址与推理 Key，选择归属站点（空白创建新站点），读取目录后确认分组、采购币种换算、加价和模型即可导入。同一站点不同分组分别填写其 Key；地址及协议必须一致。

新模型保持未发布。启用分组、完成连通性测试、补齐采购价后，在“模型与定价”选择模型并批量发布；逐项结果显示阻塞原因。同步提交后返回任务 ID，在“运行记录”查看阶段、原因、HTTP 状态和重试入口。

销售规则支持百分比与按计费单位固定 USD 金额，继承顺序为模型→分组→站点→全局，默认加价20%。修改必须预览再应用；采购价或规则变化会使预览失效。模型手工售价受到保护，模型级“恢复继承”才解除覆盖。

旧集合接口使用兼容分页；所有表格共用可选分页，默认20，10/20/50/100可选，全部最多200。站点、分组、网关模型和运行记录采用数据库分页。

好易智算历史凭据若提示无法解密，在分组设置重新填写有效 Key；系统不会猜测或替换原 Key。

# New API 两步接入与自动同步

## 操作入口

管理后台 → 渠道治理 → **New API 快速接入**。

1. 填写站点地址与推理 API Key，读取模型和价格。如果价格页需要账号身份，可展开填写上游账号访问令牌及账号 ID；这不是登录密码，也不是推理 Key。
2. 确认推理 Key 对应的固定上游分组、销售倍率、报价单位折合 USD 的比例，选择模型并查看采购价与售价，点击 **导入渠道和价格**。

默认销售倍率为 1.2；标准 New API 报价单位折合 USD 填 1。站点如果重新定义额度币种、或充值成本不同，需要填写实际折算值，系统不会根据页面人民币符号猜测采购价。分组必须与该推理 Key 在上游的配置一致，不能靠切换本项目下拉框改变上游权限。自动分组 Key 应先在上游设置为固定分组。

地址支持省略 HTTPS、末尾 `/v1`、`/v1/models` 或 `/v1/chat/completions`，并保留反向代理路径。接口目录最多接受 10000 个模型且不静默截断；单渠道仍受当前结构的 500 个所选模型和模型名称合计 2000 字符限制，超出可分批接入。

导入一次保存渠道、模型、价格和同步设置，使用数据库事务。推理 Key 与可选的价格访问令牌分别加密保存，界面、响应与同步状态不包含明文。新渠道和新模型默认未发布，实际调用测试后再启用。

## 自动同步行为

默认每 15 分钟检查通过该入口创建的渠道。后台 **上游与分组** 页面显示上游分组、最近成功同步时间、结果摘要，并提供立即同步和设置。

| 上游变化 | 本项目行为 |
| --- | --- |
| 标准价格或分组倍率变化 | 更新采购价格，按已生效加价规则更新继承售价，保留手工价 |
| 出现新模型 | 按设置自动导入为未发布模型；最初未勾选的模型不会在下一次同步中被擅自导入 |
| 模型或分组连续两次完整快照缺失 | 停用对应模型路由；整个分组消失还会停用绑定渠道 |
| 被停用的模型/分组重新出现 | 更新目录和价格，清除缺失计数，保留停用状态供人工发布 |
| 超时、HTTP 错误、格式异常、已声明的分页/截断结果 | 不将失败目录当成空目录；不累计该失败目录的删除证据 |
| 模型目录成功，价格读取失败 | 模型目录可独立参与模型缺失判定；价格和分组缺失判定不更新 |
| 分组在完整价格目录中消失，同时推理 Key 已不可用 | 可以用连续两次分组缺失证据停用该分组及其路由 |
| 价格变为表达式或不支持的规则 | 标记待配置、停用对应路由，保留历史金额，不把未知价格覆盖成零 |
| 导入新模型超出当前渠道容量 | 暂不导入，状态提示容量不足；后续同步会重试 |

不硬删除渠道或模型历史，不影响其他上游同名模型。后台可暂停自动同步、关闭新模型导入、关闭价格覆盖以保留手工定价，也可调整销售倍率和报价单位折算值。暂停自动同步后仍允许管理员手动同步。

数据库租约防止同一渠道在多实例间同时同步；网络获取完成后在事务中核对渠道地址和凭据未变化，再更新目录。价格凭据绑定初次接入的地址，修改渠道地址后同步会报错，需重新接入。删除渠道时同时清除该渠道同步状态及保存的价格凭据。

## 价格解析

标准倍率模式使用以下计算，金额存为 USD：

```text
输入成本 / 1M Token = model_ratio × 2 × group_ratio × unitUsd
输出成本 / 1M Token = 输入成本 × completion_ratio
缓存读取成本 = 输入成本 × cache_ratio
缓存写入成本 = 输入成本 × create_cache_ratio
按次成本 = model_price × group_ratio × unitUsd
本站售价 = 对应采购成本 × saleMarkup
```

缓存字段省略时按标准 New API 默认值处理：读取倍率 1，写入倍率 1.25。缓存写入一小时价格按标准写入价格的 1.6 倍记录。按次计费映射为本项目 TASK 单位；实际端点和业务能力仍需验证。

仅支持能明确解析的标准 Token 与按次计费。表达式计费、插件计费、多模态独立倍率和非法/缺失的关键价格字段标为待配置；不执行上游表达式，也不以普通档位价格代替动态费用。关闭价格同步后保留管理员手工价格。

模型权限以推理 Key 的 `/v1/models` 为依据，并与选定分组的价格模型清单取交集。`/api/pricing` 的公开目录可能与登录账号目录、专属倍率不同；有专属倍率或受保护价格页时应配置相应账号访问令牌。令牌过期后会提示价格不可用，不自动回退到可能具有不同权限范围的匿名目录。无法访问价格目录时允许按已知分组导入未定价模型，但无法可靠同步分组是否消失。

## 配置和部署

新增数据库迁移：`V25__new_api_synchronization.sql`。按项目正常流程构建并重启后端，由 Flyway 执行迁移；前端需更新构建。本次没有修改真实上游账户或替真实渠道启用同步。

```yaml
new-api:
  sync:
    enabled: true
    cron: "0 */15 * * * *"
```

可用环境变量 `NEW_API_SYNC_ENABLED` 和 `NEW_API_SYNC_CRON` 覆盖。渠道级开关保存在数据库中；全局关闭仅停止定时任务，管理员仍能手动同步。

管理员接口：

- `POST /admin/api/channels/new-api/preview`：地址、Key、可选价格凭据及分组/倍率 → 模型、可用分组及价格预览。
- `POST /admin/api/channels/new-api/connect`：另提交名称、模型、同步开关 → 创建未发布渠道。
- `GET /admin/api/channels/new-api/sync`：同步状态列表，排除凭据列。
- `POST /admin/api/channels/new-api/{id}/sync`：手动同步。
- `PUT /admin/api/channels/new-api/{id}/sync`：调整自动同步、新模型导入、价格覆盖、销售倍率、报价折算及价格凭据。

手动连接、同步和配置操作记录管理员审计。目录请求不跟随重定向，复用项目公网 HTTPS/私网访问限制，不向第三方回显其原始错误响应。导入请求若网络超时，应先刷新渠道列表核实结果，再重试，避免重复创建。

## 与 New API 的关系

本项目作为 New API 中转站的下游客户端，通过标准 API 对接，复用自己的路由、密钥加密、模型身份、定价和用量体系。没有嵌入 New API 服务、导入其数据库或移植其源码。快速入口会将纯图片分组标记为 `openai-image`，映射到 `/v1/images/generations`，并使用专用图片健康探针；文本分组仍使用 `openai-chat`。其他任务型协议不会被猜测或自动转换。

`tiered_expr` 价格仅解析受限的 `service_tier` base/priority Token 系数，不执行上游表达式。后台会展示按当前上游分组倍率换算的两档报价；在本站计费无法按每次请求的 `service_tier` 切换前，模型仍保持待定价和禁止发布。

### 前台渠道展示

快速接入第二步可填写「前台公开渠道名」，发布后模型广场的渠道筛选会显示该名称；留空仍归入「平台智能路由」。已有渠道可在后台「展示映射」配置公开代号和公开显示名。内部渠道名称不会自动公开。

同一模型由多个公开渠道供应时，每个渠道的筛选都包含该模型，计数按模型去重。保存已绑定 New API 同步的渠道会保留其 New API 来源标识，避免普通编辑使自动同步失效。同步统计中的「新增」是本次新导入的模型数量，「更新价格」是已有模型更新报价的数量，并不表示发布状态或前台展示名称。


### 统一全分组目录

渠道治理中的全分组目录读取 `/admin/api/channels/new-api/catalog`，展示所有渠道，按渠道名称多选过滤，浏览器记住展示选择。选项来自渠道的 `name`，不使用接入类型的 `source_name`；编辑渠道名称即可修改选项。每个分组独立展示模型数量、凭据是否配置、公开名称和同步状态，不返回凭据。

- 标准 New API：继续使用 `/v1/models` 和 `/api/pricing`，保留倍率、报价单位和价格更新开关。
- 好易智算：通过统一目录适配器读取实时模型接口，保留原有协议、别名和已核验定价。价格接口不兼容标准 New API，新增模型价格保持待配置。实时读取失败时不回退到本地清单执行同步。
- AiAPIBank：通过统一入口一键预览或导入全分组，复用已配置分组 Key 和原生分组倍率、阶梯及按次价格，不将内部来源标识强改为标准 New API。没有 Key 的分组保留待配置。

已配置的原生适配渠道和标准 New API 每 15 分钟自动刷新；AiAPIBank 每日 03:20（Asia/Tokyo）发现全量分组。每个渠道可单独暂停自动同步。目录展示选择不会开关渠道，也不会改变模型发布状态。
